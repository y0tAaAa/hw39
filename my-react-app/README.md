# React Components Demo 🚀

Проект демонструє створення та управління Stateful, Stateless та Class компонентів у React з використанням Vite.

## Особливості проекту

### Компоненти

#### 1. **Counter** (Stateful Component - Функціональний)
- Використовує хук `useState` для управління станом
- Керує лічильником з функціями збільшення, зменшення та скидання
- Дозволяє користувачеві змінювати крок збільшення
- Модерний UI з градієнтом та анімаціями

#### 2. **UserCard** (Stateless Component)
- Чистий функціональний компонент
- Приймає пропси: `name`, `email`, `age`, `city`, `isActive`
- Виводить інформацію користувача з красивим форматуванням
- Показує статус активності користувача
- Кольорові варіанти залежно від статусу

#### 3. **CounterClass** (Class Component - Додатково)
- Компонент на основі класів з методами життєвого циклу
- Використовує `componentDidMount`, `componentDidUpdate`, `componentWillUnmount`
- Керує станом із використанням `this.setState`
- Показує кількість кліків та поточний крок
- Демонструє альтернативний підхід до функціональних компонентів

## Порівняння підходів

| Аспект | Функціональні компоненти | Class компоненти |
|--------|-------------------------|------------------|
| **Синтаксис** | Простіший і більш читабельний | Більш багатослівний |
| **Стан** | `useState` hook | `this.state` |
| **Життєвий цикл** | `useEffect` hook | Методи компонента |
| **Зручність розробки** | Сучасний підхід | Традиційний підхід |
| **Продуктивність** | ✓ Оптимізовано | ✓ Оптимізовано |
