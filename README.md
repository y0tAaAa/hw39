# Домашнє завдання №39: React Components

Цей проект демонструє створення та управління різними типами React компонентів.

```

    ├── src/
```

## 🎯 Задача

Розробити React додаток з використанням Vite, який демонструє:

1. **Stateful компонент** - компонент зі станом (Counter.jsx)
2. **Stateless компонент** - компонент без стану (UserCard.jsx)
3. **Class компонент** - компонент на основі класу (CounterClass.jsx - додатково)

## 📚 Компоненти

### 1. Counter (Stateful Functional Component)
- Керує лічильником за допомогою `useState`
- Дозволяє змінювати крок збільшення
- Функціональність: +, -, reset

### 2. UserCard (Stateless Functional Component)
- Відображає інформацію користувача
- Приймає пропси: name, email, age, city, isActive
- Показує статус активності користувача

### 3. CounterClass (Class Component)
- Альтернативна реалізація лічильника на основі класу
- Використовує методи життєвого циклу
- Показує кількість кліків
